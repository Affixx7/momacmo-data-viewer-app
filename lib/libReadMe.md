# Lib Read Me

## amplifyconfiguration.dart
- this file is used in configuring amplify as seen in the main.dart file with the _configureAmplify() function
- this file shows the current features that have been added to the project
    - Ex: wheather the file has auth or what s3 bucket is connected
__This file is generated after you implement amplify to the project and is not included in the provided project code__

## main.dart
- this file contains the authenticator package which handles the initial auth if not logged in
- if logged in takes user to the home_page
